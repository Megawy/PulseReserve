📌 نبذة عامة عن منصة PulseReserve:
--------------------------------------------------------------------------------
منصة PulseReserve هي محرك سحابي متطور مخصص لحجز المقاعد والتذاكر للفعاليات الكبرى والحفلات والمباريات الرياضية ذات الإقبال الجماهيري الفائق (Flash-Sales). تم تصميم وبناء النظام وفق معمارية الـ Modular Monolith بالاعتماد على أحدث إصدارات تقنيات مايكروسوفت (.NET 10 LTS و C# 13) وقواعد بيانات PostgreSQL، مع واجهة مستخدم تفاعلية فائقة السرعة مبنية بواسطة Angular 22 وتقنية ASP.NET Core SignalR للتحديث اللحظي.


🎯 التحدي الهندسي (The Core Engineering Challenge):
--------------------------------------------------------------------------------
في أنظمة حجز التذاكر التقليدية، تواجه المنصات انهيارات متكررة عند طرح تذاكر الفعاليات الضخمة بسبب:
1. تدفق مئات الآلاف من المستخدمين في نفس الثانية لمحاولة حجز المقاعد ذاتها (Race Conditions).
2. حدوث "الحجز المزدوج" الكارثي (Double-Booking)، حيث يُباع المقعد نفسه لأكثر من عميل.
3. تضارب العمليات المالية واختناق قواعد البيانات عند إغلاق الجلسات المتزامنة.

تم تصميم منصة PulseReserve هندسياً لتقديم "ضمان قطعي ضد الحجز المزدوج" (Zero Double-Booking Guarantee) مع الحفاظ على زمن استجابة فائق السرعة واستقرار تام تحت الضغط العالي.


🏗️ المعمارية الهندسية للنظام (Architectural Blueprint):
--------------------------------------------------------------------------------
اعتمدت في بناء النظام على معمارية الـ Modular Monolith مقسمة إلى سياقات محددة بدقة (Strict Bounded Contexts) تفصل بين المسؤوليات وتمنع أي تشابك برمجي غير سليم، مع عزل تام لقواعد البيانات على مستوى الـ Schemas داخل PostgreSQL:

1. موديول إدارة الكتالوج والفعاليات (Catalog Module):
   - إدارة الملاعب والصالات، قطاعات الجلوس (Sections)، الصفوف (Rows)، والمقاعد الفردية (Seats).
   - نظام تسعير مرن ومتغير لكل فعالية (Event-scoped pricing) يفصل بين الهيكل الفيزيائي للمكان والعقود التجارية.
   - تحكم في التزامن المتفائل على مستوى التجمع (Aggregate Optimistic Concurrency Token) لحماية سلامة البيانات.

2. محرك الحجز والتزامن الذري (Reservation Engine):
   - جرد مخصص للمقاعد لكل فعالية (Per-event Seat Inventory) يتعامل مع المقعد كوحدة ذرية.
   - تطبيق خوارزمية الحجز الشرطي باستخدام (Ordered FOR UPDATE SKIP LOCKED) على مستوى محرك PostgreSQL مباشرة، مما يمنع حدوث أي Deadlocks أو حجز مزدوج نهائياً دون الحاجة إلى طبقات وسيطة هشة.
   - قفل مؤقت ذكي للمقاعد (Smart Hold TTL) لمدة 10 دقائق يتم تجديده أو إلغاؤه آلياً لتحرير المقاعد لمن ينتظر.

3. موديول المدفوعات والمطابقة المالية (Payments & Checkout):
   - آلة حالات مالية مستقلة تماماً (Independent Payment State Machine) مفصولة عن قفل المقاعد.
   - تكامل متعدد مع بوابات الدفع العالمية والمحلية (Stripe و Paymob) بالإضافة إلى محاكي دفع داخلي للاختبارات السريعة.
   - نظام مطابقة مالية آلي (Automated Reconciliation Engine) لمطابقة المعاملات، رصد الشذوذ المالي (Anomalies Detection)، ومعالجة الاسترداد التلقائي واليدوي (Refunds Management).

4. نمط صندوق الصادر التبادلي (Transactional Outbox Pattern):
   - يضمن وصول الرسائل والأحداث التكاملية (At-Least-Once Delivery) ومعالجتها داخلياً دون فقدان أي عملية سداد أو حجز، مع فصل مسار العمليات المتزامنة عن التأثيرات الجانبية.

5. موديول الهوية والتحقق (Identity Module):
   - حماية متقدمة ضد هجمات الـ CSRF والـ XSS عبر ملفات تعريف ارتباط آمنة ومشفرة (HttpOnly Secure Session Cookies).
   - تشفير كلمات المرور باستخدام أحدث معايير الأمان العالمية (Argon2id).


⚡ الميزات والخصائص الفنية التفاعلية:
--------------------------------------------------------------------------------
• خريطة مقاعد تفاعلية مباشرة (Live Interactive Seat Map):
  واجهة مستخدم مبتكرة تمكن العميل من استعراض خريطة الاستاد/المسرح، اختيار مقاعده، ومشاهدة حالات المقاعد (متاح، تم اختياره، محجوز لك، محجوز لشخص آخر، غير متاح) في الزمن الحقيقي دون الحاجة لتحديث الصفحة.

• التحديث بالزمن الحقيقي (ASP.NET Core SignalR):
  بث فوري لجميع عمليات حجز أو تحرير المقاعد لجميع المتصفحين في نفس اللحظة عبر WebSockets، مما يمنح تجربة مستخدم سلسة ومثيرة أثناء فترات المبيعات الخاطفة.

• لوحة تحكم إدارية متكاملة للعمليات المالية (Admin Operations Console):
  لوحة قيادة توضح مؤشرات الأداء الحية، إحصائيات المعاملات، مهام المطابقة المعلقة، فحص سجل الصندوق الصادر (Outbox Monitor)، وإجراء عمليات الاسترداد بنقرة زر واحدة.

• تذاكر رقمية فورية وآمنة:
  إصدار تذاكر إلكترونية فور تأكيد الدفع تحمل معرفات غير قابلة للتخمين ورموز باركود وQR Code للتحقق السريع عند بوابات الدخول.


🛡️ هندسة الجودة والاختبارات الآلية (Quality Assurance & Testing):
--------------------------------------------------------------------------------
المشروع ليس مجرد نموذج شكلي، بل مبني وفق أعلى معايير الشركات التقنية الكبرى:
- اختبارات معمارية آلية (Architecture Tests عبر NetArchTest): تضمن عدم انتهاك حدود الموديولات وحظر أي اعتماديات دائرية على مستوى الـ CI/CD.
- اختبارات تكامل معزولة (Integration Tests عبر Testcontainers): تجري اختبارات دورية ضد قواعد بيانات PostgreSQL 17 حقيقية داخل حاويات Docker يتم إنشاؤها وإتلافها آلياً.
- تغطية شاملة باختبارات الوحدات (Unit Tests) لجميع قواعد العمل والحالات الحرجة لضمان خلو النظام من أي ثغرات أو أخطاء برمجية.


💻 حزمة التقنيات المستخدمة (Technology Stack):
--------------------------------------------------------------------------------
• الواجهة الخلفية (Backend):
  - C# 13 / .NET 10 LTS
  - ASP.NET Core 10 Minimal APIs
  - Entity Framework Core 10 & Npgsql
  - ASP.NET Core SignalR (WebSockets Real-time Hub)
  - MediatR & Vertical Slice Architecture

• قاعدة البيانات وحلول التخزين (Database & Persistence):
  - PostgreSQL 17 (Schema-per-Module Isolation)
  - Raw Concurrency Optimization (FOR UPDATE SKIP LOCKED)

• الواجهة الأمامية (Frontend):
  - Angular 22 (Standalone Components & Signals)
  - TypeScript & RxJS
  - SCSS بتصميم متجاوب يدعم مختلف مقاسات الشاشات والجوال

• إدارة البيئة والجودة (DevOps & Testing):
  - Docker & Docker Compose
  - Testcontainers (PostgreSQL Disposable Containers)
  - NetArchTest.Rules & xUnit & FluentAssertions
  - GitHub Actions CI Pipeline
